MUM FLORENCE v3  (designed by Godwin Akwabeng)

1. In your GitHub repository (mum): open the old zip file(s) > trash icon > Commit changes.
2. Add file > Upload files > drag in MumFlorence-v3.zip (do not unzip) > Commit changes.
3. Actions tab: wait for the green tick (about 8 minutes). Releases > download app-debug.apk.
4. UNINSTALL the old Mum Florence from your phone first, then install the new one.
5. Open it, tap "Set up everything".
